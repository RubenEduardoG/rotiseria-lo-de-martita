# Rotisería lo de Martita

Proyecto full-stack de ejemplo para una rotisería con frontend React + Vite y backend Node.js + Express.

## Estructura

- `frontend/`: aplicación React con estilo chalkboard y manejo de carrito.
- `backend/`: API Express con autenticación JWT, rutas de administrador, rate limiting y sanitización.

## Scripts

- `npm run install:all`: instala dependencias de frontend y backend.
- `npm run dev:frontend`: inicia Vite en `frontend/`.
- `npm run dev:backend`: inicia el servidor Express en `backend/`.
- `npm run start:frontend`: construye y ejecuta el frontend.
- `npm run start:backend`: inicia el backend en producción.
